научно-исследовательским работам. Твоя задача — сгенерировать
5 разных коротких текстовых фрагментов в стиле проектных
документов и научных отчётов (заявки на грант, отчёты по этапам НИР,
аннотации к научным регистрам), стилистически близких к корпусу
ГИСНаука.

ТРЕБОВАНИЯ К КАЖДОМУ ФРАГМЕНТУ:

1. Объём: 1–3 предложения, 80–250 символов. Не энциклопедия,
   не реферат, не описание раздела науки.

2. Один из стилей (выбирай разные между фрагментами):
   - Объект и цель исследования: «Объектом исследования являются …»,
     «Целью работы является разработка …», «Предметом изучения служат …».
   - Этап работ / методология: «На текущем этапе проведены …»,
     «Разработан макет …», «Получены экспериментальные данные …».
   - Содержание разработки: «Разработана модель …», «Создан программный
     модуль …», «Предложен метод …», «Построена база данных …».
   - Результат / научная новизна: «Научная новизна заключается в …»,
     «Получены численные оценки …», «Установлены закономерности …».
   - Прикладное применение: «Результаты применимы для …»,
     «Полученные данные могут быть использованы при проектировании …».

3. Лексика — конкретные технические термины предметной области (4–7
   терминов на фрагмент, без английских скобок). Профессиональный
   академический русский. Без маркетинга и оценочных слов.

4. Каждый фрагмент семантически принадлежит целевой теме —
   тематика {label} должна читаться без двусмысленности. Не выходить
   на соседние темы.

5. Стилистическое разнообразие: фрагменты должны различаться
   по структуре предложения, лексике и фокусу. Не парафразировать
   один и тот же тезис разными словами — это разные аспекты темы.

ЗАПРЕЩЕНО:
- маркеры списка, нумерация, заголовки, кавычки;
- вводные «Описание:», «Это область науки, посвящённая …», «Данный
  концепт описывает …»;
- упоминание ГРНТИ-кодов, названий организаций, имён, годов, чисел;
- вопросительные и побудительные предложения;
- английский язык.

ФОРМАТ ВЫХОДА:
Просто 5 фрагментов, каждый на отдельной строке, без нумерации,
без разделителей, без пустых строк между ними. Только сами фрагменты.
